
# SmartSupport AI

An AI-powered Customer Support Agent built using Python,
Streamlit, Groq GPT-OSS 120B and Excel.

## Features

- AI Customer Support Chatbot
- Excel Customer Database
- Order Tracking
- Customer Information Lookup
- Complaint Registration
- Automatic Support Ticket Generation
- Refund and Return Policy Assistance
- Admin Dashboard
- Downloadable Excel Reports

## Technologies

- Python
- Streamlit
- Groq API
- Pandas
- OpenPyXL
- Excel

## Installation

1. Clone this repository.
2. Install requirements:

   pip install -r requirements.txt

3. Configure GROQ_API_KEY in Streamlit Secrets.
4. Run the application:

   streamlit run app.py

## AI Model

openai/gpt-oss-120b

## Database

customer_support_database.xlsx

## Important

This is a demonstration project using fictional
customer data. Do not upload real customer information
